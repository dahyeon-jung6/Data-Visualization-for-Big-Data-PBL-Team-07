# ✈️ 해외여행 기간과 소비지출의 관계 분석

## 연구 제목
방문국가에 따른 해외여행 기간과 소비지출 관계의 차이 분석:
2025년 국민여행조사를 중심으로

**2026 ICT플랫폼학회 동계학술대회 연구**

## 연구 질문
한국인의 일본·베트남 해외여행에서
여행기간과 총지출액의 관계는 어떻게 다른가?

## 분석 자료
- 출처: 2025년 국민여행조사 해외여행 원자료
- 전체 분석 기록: 2,295건
- 일본·베트남 3~7일 비교: 1,408건
- 일본: 921건
- 베트남: 487건

## 주요 연구 결과
- 연령·소득 보정 탄력성: 0.8153
- 방문국가 추가 보정 탄력성: 0.8071
- 일본 여행기간 탄력성: 0.7034
- 베트남 여행기간 탄력성: -0.0090
- 국가별 기울기 차이 HC3 p-value: 9.7e-08

전체 표본에서 방문국가를 추가했을 때
탄력성의 변화는 크지 않았습니다.

일본·베트남의 3~7일 비교에서는 국가별
기간–지출 관계 차이가 탐색적으로 관찰됐습니다.

단, 4~5일로 제한하면 통계적 차이에 대한
근거가 충분하지 않았습니다.

## 시각화
- 3~6일 여행일수별 가중평균 지출액
- 3~6일 방문국가별 표본 수
- 3~7일 국가별 기간–지출 탄력성
- 민감도 분석

## 파일 구성
- streamlit_app.py: 대시보드
- requirements.txt: 실행 환경
- data/: 집계 결과 CSV
- assets/: 포스터 PDF

## Streamlit
https://team07-travel-analysis.streamlit.app/

## 연구 방법과 한계
조사 가중치 WT_OVER를 사용한 WLS 회귀분석과
HC3 강건 표준오차를 적용했습니다.

복합표본 설계를 완전히 반영한 추론은 아니며,
관찰자료이므로 인과효과로 해석하지 않습니다.

첫 번째 해외여행과 첫 번째 방문국가를
기준으로 분석했습니다.

## 데이터 이용
원자료 및 응답자별 기록은 포함하지 않습니다.
집계 결과의 공개 범위도 제공기관 이용 조건을
확인한 후 결정해야 합니다.
