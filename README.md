# ✈️ 2025 해외여행 소비지출 분석

### 연령대 및 가구소득 수준에 따른 해외여행 소비지출 차이 분석

**Big Data Visualization PBL | Team 07**

---

## 📌 Project Overview

2025년 국민여행조사 원자료를 활용하여 연령대와 가구소득 수준에 따른 해외여행 소비지출의 차이를 분석하고, 이를 인터랙티브 대시보드로 시각화하는 프로젝트입니다.

특히 여행기간을 통제했을 때 연령대 및 가구소득별 지출 차이가 어떻게 변화하는지 탐색합니다.

## 📊 Key Findings

| 주요 지표 | 분석 결과 |
|---|---|
| 분석 표본 | 2,295명 |
| 1인당 가중평균 여행 지출액 | 약 142.7만원 |
| 평균 숙박일수 | 약 3.70박 |
| 연령대 차이 | 여행기간 통제 후 유의하지 않음 |
| 가구소득 차이 | 여행기간 통제 후에도 유의 |
| 연령 × 소득 상호작용 | 유의하지 않음 |

*첫 번째 해외여행 기록 기준이며, 통계적 유의성 판단은 가중 WLS와 HC3 강건 표준오차를 이용한 탐색적 결과입니다.*

## 🎯 Research Questions

- **RQ1.** 연령대에 따라 해외여행 소비지출에 차이가 있는가?
- **RQ2.** 가구소득 수준에 따라 해외여행 소비지출에 차이가 있는가?
- **RQ3.** 연령과 가구소득을 함께 고려했을 때 소비지출 패턴은 어떻게 달라지는가?
- **RQ4.** 여행기간을 통제하면 연령 및 소득별 지출 차이는 어떻게 변화하는가?
